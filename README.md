# KT10 — Практикум по алгоритмам

Шесть решений на Java.

## Задачи

1. **Task1** — максимальное число непересекающихся интервалов (жадный алгоритм по времени окончания).
2. **Task2** — стек с минимумом и максимумом за O(1) в худшем случае.
3. **Task3** — k-й элемент массива с помощью Quickselect.
4. **Task4** — планирование заказов по срокам и прибыли с DSU для поиска свободного слота.
5. **Task5** — LFU-кэш с вытеснением по частоте и давности использования.
6. **Task6** — выбор k ближайших к началу координат точек по заданному компаратору с Quickselect.

## Компиляция и запуск

Из корня проекта:

```bash
javac src/Task1.java
java -cp src Task1
```

Для остальных задач замените `Task1` на `Task2`, `Task3`, `Task4`, `Task5` или `Task6`.

## Сложность

- Task1: O(n log n).
- Task2: O(1) на команду в худшем случае.
- Task3: O(n) в среднем, O(1) дополнительной памяти сверх входного массива.
- Task4: O(n log n) плюс почти O(1) на поиск слота.
- Task5: O(1) в среднем на команду.
- Task6: O(n) в среднем для отбора и O(k log k) для сортировки выбранных точек.
